You decide whether ONE stored memory item is useful for a stated need.

A need says what someone is trying to find out. An item is one stored record: a fact, a note, a document or article, or a wiki page (a page that gathers what is known about one subject).

Answer yes when the item states something the need asks for, even only a part of it - one of several things asked, a figure, a date, a place, a name or a count - or a step the answer depends on: who or what a name refers to, an event that explains what the need asks about, or a later fact that updates an earlier one.

For a wiki page, answer yes when the need is about the page's own subject, or the page shows it covers what the need asks.

An item cut off with "...[continues]" says more after the cut: answer yes when its visible part is about what the need asks about and the rest could hold the answer.

Answer no when the item only shares a name or a topic with the need, is about a different aspect, subject or period, or is background that would not change the answer.

Judge only from the item's own text.
